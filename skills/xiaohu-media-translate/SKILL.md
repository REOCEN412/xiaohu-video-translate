# Xiaohu Media Translate

Use this skill to run the xiaohu audio/video translation workflow from Codex. Keep processing local by default: do not upload media to third-party services unless the user explicitly asks.

## Inputs

Accept any of these:
- URL: download first, then process.
- Local path: use it directly.
- Uploaded file: if the user says "uploaded" but gives no path, search the current workspace, `~/Downloads`, `~/Desktop`, `~/Documents`, and `/tmp`.
- Fuzzy title or keyword: run `scripts/find_media.py "<query>"` and ask only if multiple plausible candidates remain.

Supported media extensions include `.mp3`, `.m4a`, `.wav`, `.aac`, `.flac`, `.ogg`, `.mp4`, `.mov`, `.mkv`, `.webm`, `.avi`, and `.m4v`.

## Core Workflow

1. Resolve the input media path.
   - For local or uploaded media, prefer `scripts/find_media.py` before asking the user to re-send paths.
   - For URLs, reuse `xiaohu-video-md` or `xiaohu-video-download` download steps when those skills are installed.

2. Prepare audio for transcription.
   - If the input is audio, use it directly or normalize to mp3 when ffmpeg needs a stable input.
   - If the input is video, extract audio with ffmpeg and keep the video for later subtitle burn-in.

3. Transcribe with the existing xiaohu script.
   - Prefer `xiaohu-video-md/scripts/transcribe_srt.py` or `xiaohu-video-download/scripts/transcribe_srt.py`.
   - Use word-level timestamps for any subtitle burn-in or audio-subtitle merge.
   - Do not use `whisper-cli` for burn-in timing unless both script engines are unavailable.

4. Translate and polish subtitles.
   - Use `xiaohu-subtitle-polish` rules for Chinese SRT or bilingual SRT.
   - Bilingual SRT format must keep translated Chinese on line 1 and source text on line 2 for each cue.
   - Convert bilingual SRT to ASS with `xiaohu-subtitle-polish/scripts/bilingual_ass.py` when available.

5. Produce the final artifact.
   - Video input: burn Chinese SRT or bilingual ASS into the original video, following `xiaohu-video-md` burn-in rules.
   - Audio input: create a shareable MP4 with a static background, the original audio, and burned subtitles:
     ```bash
     python3 scripts/audio_subtitle_mux.py "<audio.mp3>" "<subtitle.ass-or-srt>" --output "<out.mp4>" --title "<title>"
     ```
   - For bilingual audio output, pass the ASS generated by `bilingual_ass.py` so Chinese and source text can use different sizes.

6. Generate Markdown when requested or when following the full translation pipeline.
   - Read the SRT, remove indexes and timestamps, then follow the existing xiaohu Markdown rules.

## Local Search

Use this before asking for file locations:

```bash
python3 scripts/find_media.py "<keyword>" --limit 20
```

Useful variants:

```bash
python3 scripts/find_media.py --kind audio --recent 7
python3 scripts/find_media.py --kind video --root "$PWD" --root ~/Downloads
python3 scripts/find_media.py "interview mp3" --json
```

Treat matches in the current workspace and recent uploads/downloads as stronger candidates than older files with similar names.

## Audio + Bilingual Subtitle Merge

MP3 and most audio-only containers cannot display burned subtitles. When the user asks to "merge subtitles with MP3/audio", create an MP4 from the audio:

```bash
python3 scripts/audio_subtitle_mux.py input.mp3 bilingual.ass --output output-bilingual.mp4 --title "Episode title"
```

Defaults:
- 1920x1080 black background.
- AAC audio for broad compatibility.
- ASS subtitles use `ass=`; SRT subtitles use `subtitles=`.
- Optional `--cover cover.jpg` uses a still image background.
- Requires an ffmpeg build with `ass`/`subtitles` filters. On Homebrew, install `ffmpeg-full` if regular `ffmpeg` lacks libass; the script auto-detects `/opt/homebrew/opt/ffmpeg-full/bin/ffmpeg`, or pass `--ffmpeg` / `FFMPEG_BIN`.

If the user explicitly wants soft subtitles instead of burned subtitles, explain that player compatibility is weaker and use a video container such as MKV/MP4 only after confirming.

## Reuse Existing Xiaohu Skills

When installed side by side, call into:
- `xiaohu-video-md`: URL/local video orchestration, Markdown output, video burn-in.
- `xiaohu-video-download`: pure download and local video subtitle burn-in helpers.
- `xiaohu-subtitle-polish`: subtitle translation, polishing, bilingual SRT, and SRT-to-ASS conversion.

If those skills are not installed, use the copies in this repository under `skills/`.

## Output Rules

- Prefer writing temporary files under the configured xiaohu `output_dir/tmp/` when available.
- Prefer final deliverables under the configured `output_dir/data/`, unless the user gives an explicit absolute output path.
- Never paste secrets, cookies, `.env` values, or browser tokens into commands or logs.
- Keep original media untouched; write a new output file unless the user explicitly confirms overwrite.
